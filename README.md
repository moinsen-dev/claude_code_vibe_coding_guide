# Claude Code Starter Template

A minimal starter template demonstrating best practices for using Claude Code effectively in your development workflow.

## About This Template

This repository serves as a foundation for new projects using Claude Code. It includes essential configuration and demonstrates proven patterns for maximizing productivity with AI-assisted development.

## Getting Started

1. **Clone or use this template**
2. **Initialize your project**: Add your specific project files, package.json, etc.
3. **Configure Claude Code**: The template includes pre-configured MCP servers for enhanced capabilities

## Claude Code Best Practices

### Project Setup

- **Use CLAUDE.md**: Create a `CLAUDE.md` file in your project root to provide context about your codebase architecture, build commands, and development workflow
- **Configure MCP servers**: Leverage Model Context Protocol servers for additional capabilities (browser automation, time utilities, specialized tools)
- **Set up local settings**: Use `.claude/settings.local.json` for project-specific configurations

### Effective Communication

- **Be specific**: Provide clear, detailed requirements and context
- **Use @-mentions**: Reference specific files with @filename for targeted assistance  
- **Leverage the todo system**: Let Claude create and manage task lists for complex work
- **Use thinking mode**: Say "think" or "think harder" for complex problem-solving

### Development Workflow

- **Start with planning**: Use plan mode for complex features or refactoring
- **Incremental changes**: Break large tasks into smaller, manageable steps
- **Review and iterate**: Use Claude's ability to explain, review, and improve code
- **Leverage built-in tools**: Take advantage of search, file editing, and bash capabilities

### Configuration Features

This template includes:

- **MCP Server Configuration** (`.mcp.json`):
  - `browsermcp`: Web automation and testing capabilities
  - `sequential-thinking`: Enhanced reasoning for complex problems
  - `time`: Time zone and date utilities
